# MobiHub Mini App UI V1.5

واجهة محسنة بصريًا لنسخة V1.4 دون تغيير منطق الـ API أو جداول Google Sheets.

## التغييرات
- إعادة تصميم لوحة الخدمات والطلبات لتكون أخف وأسهل على شاشة الهاتف.
- إصلاح تكدس أزرار طلب الإذن / طلب سلفة / طلباتي: أصبحت شبكة 3 أعمدة مرنة ولا تخرج خارج الشاشة.
- تقليل تكرار روابط الطلبات والأذونات والسلف في قسم الخدمات؛ أبقينا الشكاوى وسجلات العهد كخدمات مستقلة.
- إزالة حالة التحديد الافتراضية من الأزرار؛ يظهر النموذج بعد اختيار الخدمة.
- عند اختيار طلباتي تختفي نماذج الإنشاء ويظهر سجل الطلبات.
- توحيد الحقول والأزرار والرسائل والألوان مع هوية MobiHub الأسود والبرتقالي.

## الملفات
ارفع `index.html`, `styles.css`, `app.js`, `_headers` إلى نفس مستودع GitHub / مصدر Cloudflare Pages المعتاد.
لا تستبدل `Code.gs`؛ لم يتغير في هذا الإصدار.
لا تغير Worker الخاص بالـ API Proxy.

## التحقق
- فحص JavaScript syntax.
- فحص HTML IDs المستخدمة في app.js.
- لم يتم إجراء اختبار بصري داخل Telegram أو اختبار API حي.
