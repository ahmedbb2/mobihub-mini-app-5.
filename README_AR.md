# MobiHub — تحديث مستلمي إشعارات التحويلات (v1.13.3)

## ما الذي تغير؟
- إضافة وحدة Super Admin لإدارة مستلمي تنبيهات التحويلات.
- إضافة مستلم بالاسم وTelegram Chat ID، مع منع التكرار.
- تفعيل/إيقاف/حذف المستلم وإرسال رسالة اختبار.
- إنشاء ورقة Google Sheets باسم `مستلمو إشعارات التحويلات` تلقائيًا.
- إرسال نسخة معلوماتية بلا أزرار اعتماد أو رفض إلى المستلمين النشطين.
- إبقاء إشعار Finance/Super Admin الحالي بأزرار المراجعة كما هو.
- استبعاد حسابات Finance/Super Admin من النسخة المعلوماتية لتجنب وصول إشعارين للحساب نفسه.
- لا تعديل على Cloudflare Worker أو iPhone Shortcut أو مسارات الاستقبال.

## الملفات
- `Bot-2.gs`: مشروع البوت الرئيسي؛ استبدل ملف Bot-2.gs الحالي بمحتواه.
- `Code.gs`: مشروع Mini App API؛ استبدل ملف Code.gs الحالي بمحتواه.
- `app.js`, `index.html`, `styles.css`: ملفات واجهة Mini App.

## شروط مهمة قبل النشر
1. تأكد أن مشروع Mini App لديه `SPREADSHEET_ID` نفسه المستخدم في مشروع البوت الرئيسي.
2. خذ نسخة احتياطية من ملفات وإصدار Apps Script الحالي قبل الاستبدال.
3. حدّث مشروع Apps Script الرئيسي بملف `Bot-2.gs` ثم احفظه.
4. حدّث مشروع Mini App بملفات `Code.gs`, `app.js`, `index.html`, `styles.css`.
5. انشر إصدارًا جديدًا من Web App الخاص بـ Mini App، مع الحفاظ على إعدادات الوصول الحالية.
6. افتح Mini App بحساب Super Admin، ثم وحدة «مستلمو إشعارات التحويلات».
7. أضف Chat ID لموظف بدأ المحادثة مع البوت بالفعل، ثم استخدم «اختبار».
8. اختبر رسالة تحويل وارد تجريبية/حقيقية وفق إجراءاتك، وتأكد من وصول التنبيه المعلوماتي ومن بقاء أزرار المراجعة لدى Finance/Super Admin فقط.

## ملاحظات تشغيلية
- الموظف المستلم لا يحتاج دور Admin أو Finance؛ الإضافة هنا لا تمنحه أي صلاحية داخل النظام.
- يجب أن يفتح الموظف البوت ويضغط `/start` أولًا حتى يستطيع Telegram استقبال رسائل البوت منه.
- رسالة SMS تظل مؤشرًا يحتاج تحققًا، وليست إثباتًا لوصول الأموال.
- هذا التحديث لم يُنشر على حسابك أو Google Apps Script؛ الملفات جاهزة للمراجعة والنشر اليدوي.

## الفحوصات المنفذة
- فحص JavaScript للواجهة باستخدام `node --check`.
- فحص الصياغة النحوية لملفي Apps Script باستخدام `node --check` على stdin.
- لم يتم إجراء اختبار إرسال فعلي إلى Telegram أو اختبار تشغيل حي على Google Sheets؛ يتطلب ذلك بيئة حسابك وصلاحياتها.
