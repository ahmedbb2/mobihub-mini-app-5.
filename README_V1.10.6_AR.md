# MobiHub Mini App V1.10.6 — استكمال حفظ فحص الأجهزة

## ما تم إضافته
- حفظ نتائج فحص الجهاز في ورقة `سجل فحص الأجهزة`.
- استرجاع آخر جلسة محفوظة لنفس رقم الطلب ونوع الجهاز.
- إمكانية استكمال الفحص لاحقًا من آخر حالة محفوظة.
- تسجيل نتيجة كل اختبار: `سليم` أو `مشكلة` أو `لم يختبر` أو تركه دون تقييم.
- إضافة ملاحظات مستقلة لكل اختبار.
- صلاحيات السيرفر: Super Admin وAdmin، ومسؤول الاستلام للجهاز الذي استلمه، والفني المسؤول عن الجهاز فقط.
- حفظ كل عملية إرسال كنسخة جلسة جديدة غير قابلة للكتابة فوق السجل السابق.

## الملفات المعدلة
- `Code.gs`: عمليتا API جديدتان `device_inspection_get` و`device_inspection_save`.
- `app.js`: زر فحص الجهاز، استرجاع الجلسة، تغيير نوع الجهاز، وحفظ النتائج.
- `styles.css`: تنسيق شاشة الفحص.

## شيت جديد
اسم الورقة: `سجل فحص الأجهزة`
الأعمدة:
1. التاريخ والوقت
2. معرف جلسة الفحص
3. رقم الطلب
4. نوع الجهاز
5. ترتيب الاختبار
6. اسم الاختبار
7. النتيجة
8. ملاحظات الاختبار
9. منفذ الفحص Chat ID
10. منفذ الفحص

يتم إنشاء الورقة تلقائيًا عند أول حفظ. إذا كانت موجودة مسبقًا فيجب أن تطابق أسماء الأعمدة العشرة بالترتيب.

## ملاحظات مهمة
- الحزمة مبنية على V1.10.5؛ لا تستبدل بها الإنتاج قبل الاختبار.
- الواجهة الحالية تضيف زر الفحص داخل وحدة الأجهزة الإدارية. واجهة الفني المستقلة لعرض الأجهزة المسندة إليه ما زالت مهمة منفصلة.
- يتم تخمين نوع الجهاز من اسمه، والافتراضي iPhone إذا لم يتعرف النظام عليه؛ يمكن تغييره يدويًا من شاشة الفحص.
- كل حفظ ينشئ Snapshot جديدًا للجلسة؛ آخر Snapshot هو الذي يُسترجع.
- لم يتم الاتصال ببيانات Sheets أو Telegram الحقيقية ولم يتم النشر من بيئة البناء.

## خطوات اختبار TEST
1. خذ نسخة احتياطية من Apps Script وCloudflare Pages TEST.
2. ارفع `Code.gs` إلى مشروع Apps Script TEST ثم Deploy كإصدار جديد.
3. ارفع ملفات الواجهة إلى Cloudflare Pages TEST.
4. افتح جهازًا تجريبيًا من وحدة الأجهزة واضغط `فحص الجهاز`.
5. اختر نوع الجهاز وتأكد من ظهور عناصر الفحص وتعليماتها.
6. قيّم بعض الاختبارات واحفظ.
7. أغلق النافذة وأعد فتح الفحص لنفس الجهاز والنوع؛ يجب أن تعود النتائج والملاحظات.
8. أكمل بقية الاختبارات واحفظ مرة أخرى.
9. راجع ورقة `سجل فحص الأجهزة` وتأكد من وجود Snapshot جديد لكل عملية حفظ.
10. جرّب الوصول إلى جهاز غير مسموح به بحساب فني آخر؛ يجب أن يرفض السيرفر الطلب.
